# First task — Repro

## Task

> Read this bug report and reproduce it in staging using a fresh test account. Return exact steps, expected and actual behavior, screenshots, browser and OS details, relevant console or network notes, and a minimal test case if possible. Do not use production customer data.

Attach the ticket, HAR, or screenshot. Provide staging credentials via secure handoff, not chat.

If staging is not signed in yet:

> From the attached report only, write a repro plan: environment, test account needs, step list, and what evidence to capture. Do not open production. Do not contact the reporter.

## When that looks right

> Save the process we just used as a skill called “Reproduce bug.” Include the staging-only rule, the required pack fields, and that ticket writes always need approval.

Keep `.grok/skills/reproduce-bug/SKILL.md` in this repo in sync.
