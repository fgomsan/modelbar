# Share a Bot

A public share link copies **configuration** (identity, description, skills, routines). It does **not** copy the computer, logins, or chat history. Anyone with the link can view that config on x.ai.

Before you copy the link:

1. Search profiles, skills, and routines for API keys, cookies, customer names, internal hostnames, and staging passwords.
2. Remove `/workspace` files you would not put in a public document.
3. Confirm the Bot description has no private CRM views or personal emails.
4. Recipients need the Grok Bot app to **Add to Grok Bot**. Adding accepts the third-party bot terms.

Official: [Share a Bot](https://docs.x.ai/grok-bot/bots).
